# Traceable

**Every finding, traced to its source.**

Traceable is a hackathon project for the "Digital Dark Spot: AI-Assisted Information Gap Detection Platform" challenge (Shinchan Online Hackathon 2026). It takes a research question, collects real web sources, and surfaces information gaps, possible conflicts between sources, stale or undated pages, and a prioritized "verify next" checklist — with every finding traced to a verbatim quote from a real source. The UI clearly separates sourced information from AI-generated suggestions and uncertainty, and never claims to prove truth.
