# Design Assets

This folder holds all design reference files used during development.

## File naming conventions

| Filename | Screen |
|---|---|
| `01-home.png` | Home — question input, example prompts, how-it-works strip |
| `02-topics.png` | Confirm Topics — editable entity + topic chips |
| `03-sources.png` | Add Sources — search results, paste URL, paste text, PDF upload |
| `04-progress.png` | Progress — live stage stepper driven by SSE |
| `05-dashboard.png` | Results Dashboard — stat cards, coverage matrix, findings, checklist |
| `06-evidence-drawer.png` | Evidence Drawer — full passage, highlighted quote, confidence breakdown |

## Folders

- `screenshots/` — Stitch screenshots (PNG/JPG). Drop files here and reference them in code comments.
- `stitch-code/` — Stitch exported HTML/CSS/JS. Each export goes in its own numbered subfolder (e.g. `01-home/`).
